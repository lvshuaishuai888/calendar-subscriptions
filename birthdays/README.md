# 生日与纪念日日历（预留）

以后可在本目录单独维护生日、纪念日的 `.ics` 文件，与节假日和补班日历分开订阅。目前尚未生成可订阅文件，也没有任何真实生日数据。

## 添加前需要确定

- 公历还是农历；农历需明确闰月等规则。
- 日历中显示的名称、日期，以及是否需要提醒。
- 是否包含出生年份及是否展示年龄。
- 数据是否可以公开；私密生日资料应选择私有存储或仅在本地导入。

公历生日可使用每年重复的全天事件。农历生日需要按农历逐年换算，不能简单套用公历每年重复。

本仓库为公开仓库，提交的真实姓名、完整生日与备注可被任何人查看，并可能留存在 Git 历史中。在明确公开范围前，不上传个人生日资料。
