# 家人农历生日（2026—2035 年）

已将提供的六个农历生日按香港天文台逐年公历与农历对照表换算，生成 60 条全天事件。使用家庭称呼，不包含真实姓名、出生年份或年龄。

- 儿子：农历十一月初二。
- 爸爸：农历二月廿八。
- 妈妈：农历十月初三。
- 我：农历八月十二。
- 媳妇：农历三月初四。
- 姐姐：农历腊月廿九。

未注明闰月的日期均按普通农历月处理：每年一次，遇闰月不重复。没有使用公历每年重复规则，以免生日逐年偏移。若其中有闰月出生或需要在闰月庆祝的情况，应先调整规则。

日历文件为 `family-lunar.ics`，建议使用紫色，与绿色放假和红色补班分开。每次生日提前一天上午 09:00（北京时间 / Asia/Shanghai）提醒一次。提醒时间以 UTC 绝对时间写入文件，即使手机切换时区，也对应同一北京时间；在海外显示的当地钟点会随时区变化。每条事件使用稳定 UID，结束日期为次日，避免多显示一天。

覆盖范围按公历 2026—2035 年计算。姐姐的腊月廿九通常在公历 1—2 月，所属农历年份为前一年；下表仍按事件实际发生的公历年份列示。

## 在线订阅

```text
https://raw.githubusercontent.com/lvshuaishuai888/calendar-subscriptions/main/birthdays/family-lunar.ics
```

在 iPhone“日历 → 添加日历 → 添加订阅日历”中粘贴上面的地址，选择紫色。覆盖 2026—2035 年，2036 年及以后的日期需继续补充到同一文件中。

本文件已按资料提供者确认的公开范围发布，仅使用家庭称呼。公开仓库中的农历、公历生日日期可被任何人查看；不含出生年份或年龄。

## iPhone 提醒设置

继续使用原订阅地址，无须重复添加。客户端需刷新后才能获得本次修改，刷新可能受网络和缓存影响。在 iPhone“日历 → 日历 → 家人农历生日旁的 ⓘ”中打开“日程提醒”，并确保系统已允许日历通知。文件内已包含 60 个提醒，但手机实际通知需在设备端确认。

[Apple：打开日历日程提醒](https://support.apple.com/zh-cn/guide/iphone/iph3d1110d4/27/ios/27)。
